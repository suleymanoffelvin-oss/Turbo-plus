# TurboPlus

Azərbaycan üçün müasir, **tamamilə pulsuz** avtomobil elan platforması.

## Strategiya

### 3 əsas sütun:
1. **Etibar** — Yoxlanılmış satıcılar, reytinq, saxta elanlara qarşı qoruma
2. **Ağıllı qiymət** — Hər elanda bazar qiyməti göstəricisi
3. **Daha yaxşı təcrübə** — Təmiz, işıqlı, mobilə uyğun dizayn

### Monetizasiya:
- **İndi:** Tamamilə pulsuz (elan, VIP, irəli çəkmə — hamısı pulsuz)
- **Sonra:** Sayt böyüdükdən sonra yumşaq ödənişli xidmətlər

## Dizayn
Açıq fon + narıncı accent rənglər (istifadəçi seçimi)

- Elanlar + filtr
- Elan detallı
- Elan yerləşdirmə (pulsuz)
- Favoritlər
- Giriş / Qeydiyyat
